# API Journey — landing page

Static landing page for [API Journey](https://github.com/saiyadzaid/api-journey), the built-in,
Postman-style API client for Express. Plain HTML and CSS, no build step.

Published with GitHub Pages from the `main` branch root.

## Edit

- `index.html` — page content (features, demo, comparison)
- `styles.css` — styles; colours follow the explorer's palette, light and dark
- `assets/` — logo and explorer screenshots

To add the demo video, save it as `assets/demo.mp4` (the player shows a screenshot until then).

Preview locally with any static server, e.g. `npx serve .`
